## How to review a problem

1. Cover the solution. Read only the statement.
2. Say the pattern out loud (hashing? two pointers? window?).
3. Write the brute force first, then improve it.
4. Run the three edge cases: empty, one item, all the same.
5. State time and space complexity.
6. If you got stuck for more than 20 minutes, read the hint, close it, and redo the problem the next day.
